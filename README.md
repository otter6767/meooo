# meooo

Автор: Иван Иванов

## Требования
- Python 3.x
- Библиотеки: requests, tkinter

## Установка
1. Клонируйте репозиторий: git clone ...
2. Установите зависимости: pip install -r requirements.txt

## Получение API-ключа
1. Зарегистрируйтесь на exchangerate-api.com.
2. Получите API-ключ и вставьте его в код (см. main.py).

## Запуск
python main.py

## Примеры использования
1. Выберите валюты "из" и "в".
2. Введите сумму.
3. Нажмите "Конвертировать".
4. История операций отображается в таблице.
